Gene Expression Predictor

Predict whether a human gene sequence has High, Medium, or Low expression in liver tissue using a Transformer trained on 6-mer tokenized DNA sequences.

Input

Enter a sequence and click Predict

Confidence
Attention Rollout ? Propagates attention weights across all Transformer layers. Shows which 6-mers the model collectively attended to when making its prediction.
Input Gradient Saliency ? Computes the gradient of the predicted class score with respect to the input embeddings. Shows which 6-mers, if changed, would most alter the prediction.
Nucleotide-Level Importance ? Aggregates 6-mer saliency scores back to individual bases. Each nucleotide is coloured by the average saliency of all 6-mers it belongs to.
Saliency Profile ? Line chart of saliency scores along the sequence. Peaks indicate regions the model found most influential for its prediction.
Top 10 Most Important 6-mers ? The 10 highest-scoring 6-mers by input gradient saliency, ranked from most to least important.

About this model

🧬

Dataset

12,051 human genes from NCBI coding sequences, labeled using GTEx v8 liver median TPM. Classes split by rank into Low / Medium / High thirds.

⚙️

Model

Encoder-only Transformer (4 layers, 4 heads, d=128). Input: 6-mer tokenized DNA up to 994 tokens with CLS token prepended. Trained with label smoothing, class weights, warmup + cosine LR schedule, and reverse-complement augmentation.

📊

Performance

Test accuracy: 63.4%  |  Macro F1: 0.634  |  AUROC: 0.806 on a held-out test set of 2,411 genes.

⚠️

Limitations

Coding sequences carry limited expression signal — regulatory elements (promoters, enhancers) that drive expression lie outside the coding region. Moderate accuracy is a scientifically expected finding.
